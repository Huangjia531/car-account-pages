    云端同步设置（GitHub）

    配置后，桌面文件保存数据会自动同步到你的 GitHub 私有仓库，永久链接每次打开即拉取最新数据，无需手动导入导出。

    怎么拿令牌？ 打开 github.com 登录 → 右上角头像 Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，权限勾选 repo，复制生成的 ghp_... 填到上面。
    保存后系统会自动新建一个私有数据仓库（默认 car-account-data）并写入数据。你的财务数据只在这个私有仓库里，任何人无法通过公开网站看到。数据在你本机与这个私有仓库之间同步。
